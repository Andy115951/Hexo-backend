# 学会这5个提示词技巧，让AI帮你提升10倍工作效率

你有没有这样的经历：同样用 ChatGPT、Claude 或国内大模型，别人能让 AI 写出像样的方案和文案，你这边却总得到一句「我理解你的意思，但是……」？

问题往往不在模型，而在怎么问。近两年模型明显变强——有的会「先想再答」，有的能连着改文档、跑代码——但可复制的提问结构，依然决定输出上限。下面 5 个技巧，每个都附上可直接粘贴的模板，建议收藏后改括号里的内容就能用。

来源：[OpenAI 提示词最佳实践](https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-openai-api)

---

## 先给身份，再给任务，输出会稳很多

让 AI 扮演具体角色，比空喊「帮我写」更管用。

**可复制模板：**
```
你是一位有【N】年经验的【岗位】，擅长【具体方法/风格】。
任务：【写什么 / 做什么】
对象：【读者或用户是谁】
约束：【字数 / 语气 / 必须包含 / 禁止出现】
请直接给出成品，不要开场白。
```

**示例：** 你是一位有 10 年经验的市场营销专家，擅长故事化转化。任务：为我们的智能手表写推广文案。对象：25–35 岁职场白领。约束：800 字内，口语化，结尾带一句行动号召。

**为什么有效：** 角色等于帮模型锁定「调哪套知识」；约束等于帮它少废话、少跑题。

## 把想要的格式写死，信息才不会散

告诉它输出骨架，比事后自己整理快得多。

**可复制模板：**
```
请严格按以下结构回复（不要增减章节）：
1. 问题分析：……
2. 可选方案：至少 3 个，每个含优缺点
3. 推荐方案：只选 1 个，并说明理由
4. 下一步：3 条可执行动作
若信息不足，先列出你需要我补充的 3 个问题。
```

**适用：** 方案、周报、会议纪要、竞品对比。结构化输出也方便二次粘贴进文档或表格。写作工作流里，很多人会先让模型出大纲，再按格式填肉——本质都是「格式先行」。

---

## 丢一份你满意的样本，比讲十句「要高级」有用

这是性价比最高的一招：给样本，比空谈风格更准。

**可复制模板：**
```
下面是一份我满意的【类型】样本（风格、结构、语气请对齐）：
---
【粘贴样本】
---
请按同样格式，根据以下素材重写一版：
【粘贴素材 / 要点】
额外要求：【更短 / 更口语 / 更适合微信公众号】
```

**关键：** 样本越接近你真实要用的场景，模仿越稳。长文、邮件、纪要、客服话术都适用。若没有完整样本，至少贴一段你喜欢的开头和结尾。

## 复杂题拆成步骤；推理模型则换一种问法

对常规聊天模型，分步思考能减少遗漏。

**可复制模板（通用模型）：**
```
请分步完成，每步写完再进入下一步：
Step1 复述我的目标（确认理解）
Step2 列出关键假设与风险
Step3 给出 3 个方案并对比
Step4 推荐 1 个，并写实施清单
```

近两年出现了更擅长「内部多想一会儿」的推理类模型。对这类模型，官方建议往往是：**目标写清楚、约束写清楚，少逼它「请一步步思考」**——它本来就会在后台推理。

来源：[OpenAI o1 介绍](https://openai.com/o1/)

**可复制模板（推理模型）：**
```
目标：【最终要交付什么】
成功标准：【怎样算合格】
硬约束：【预算 / 时间 / 不能做什么】
已知信息：【粘贴】
请给出最终方案；仅在有关键不确定时简短说明假设。
```

一句话记：**普通模型靠你拆步骤；推理模型靠你写清验收标准。**

## 把第一稿当草稿，用追问把质量抬上去

一次问完美不现实。把 AI 当能改稿的同事，用短指令迭代。

**可复制追问库：**
```
- 保留结构，把【第2段】写得更具体，并补一个例子
- 语气再口语一点，去掉「赋能」「闭环」这类词
- 针对【行业/公司】重写，假设读者只有 3 分钟
- 列出你不确定的 3 处，并给出需要我确认的问题
- 压缩到【N】字，优先保留结论和行动项
```

现在不少产品还支持「改文档 / 写代码 / 连着多步做事」的 Agent 式用法（编程场景里尤其明显）。提示词逻辑不变：**目标、约束、验收标准**写清楚，再让它连做几步，你只负责卡关和验收。

## 把技巧串起来：一份可直接用的周报提示词

```
你是一位重视结果的部门经理。请根据我的工作记录写周报。
输出结构：
【本周核心成果】3 条，尽量可量化
【风险与阻塞】若无则写「无」
【下周计划】最多 3 条，按优先级
【需要支持】资源/决策/协作
语气：简洁、可直接发给上级。
工作记录：
【粘贴】
```

同一套结构，换成「方案」「复盘」「用户访谈纪要」也成立。你会发现：提示词变好之后，换哪个品牌的模型，收益都会跟着上来。

---

## 一个小提醒：好提示词可以「版本管理」

把常用模板放在备忘录或文档里，按场景命名：周报、纪要、改写口语、纠错事实。换模型时先不改结构，只改约束；这样你才能分清「是模型差，还是提示词差」。团队协作时，共享同一套模板，比每人从零玄学提问更稳。

提示词不是玄学，是把「角色、目标、格式、样本、约束」说完整。模型在变，这套骨架短期不会过时。
