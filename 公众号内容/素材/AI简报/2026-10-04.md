# 全球 AI 动态简报 · 2026-10-04

过去约一天，主线是安全与监管升温，同时开源模型和 Agent 基建继续往前推。

**1. OpenAI 安全负责人辞职，称「文化坏了」**  
曾负责重大发布安全报告的 David Robinson 离职，在《大西洋月刊》批评前沿实验室靠「试错式」部署，呼吁按核电、机场标准做多层冗余；OpenAI 回应称会加强安全，必要时暂停训练或扣发模型。  
来源：[TechCrunch](https://techcrunch.com/2026/10/03/openai-safety-employee-resigns-claiming-the-companys-culture-is-broken/)、[The Verge](https://www.theverge.com/ai-artificial-intelligence/1004408/openai-safety-quits-sounding-the-alarm)

**2. 德国 Aleph Alpha 开源 Kolibri：78B MoE、Apache 2.0、最长约 1M context**  
在德国统一日发布英德双语主权开源权重模型（约 78B 总参、约 3.5B 激活/token），权重上 Hugging Face，面向政务、工业等合规场景。  
来源：[Aleph Alpha](https://aleph-alpha.com/en/blog/kolibri-has-landed-a-sovereign-open-weight-model/)

**3. doxx.net 获 a16z 领投 3800 万美元，做「Agent 专用网络」**  
同时开放 Agentic Defined Networking 测试：给 AI Agent 限定连通并拦威胁，避免代用户操作时误入恶意站点。  
来源：[SecurityWeek](https://www.securityweek.com/doxx-net-raises-38-million-to-prevent-ai-agent-on-the-internet-misadventures/)

**4. 参议员 Warner 提出《2026 人工智能风险管理与安全法》**  
拟设联邦 AI 安全委员会和事故/漏洞数据库，批评白宫「自愿协议」路径不够。  
来源：[WHSV](https://www.whsv.com/2026/10/03/sen-warner-files-new-legislation-ai-regulations/)

**5. 白宫仍押「自愿、无罚则」AI 安全协议**  
Reuters 梳理与 Nvidia、SpaceX、OpenAI、Anthropic、Meta、Google 等签署的一页纸自愿协议（无明显违约后果），对照公众担忧升温。  
来源：[CNA / Reuters](https://www.channelnewsasia.com/business/public-fears-ai-grow-trump-digs-in-voluntary-safeguards-6429041)

**6. OpenAI 推进 ChatGPT Space：人与 Agent 共用工作区**  
面向 Pro/Business/Enterprise，整合文件与可协作页面，对接 Agent；官方文档把它写成页面、文件、共享工作的统一入口。  
来源：[Forbes](https://www.forbes.com/sites/johnwerner/2026/10/03/openai-pioneers-common-workspace-called-space-for-humans-and-agents/)

**7. Meta Muse 代理购物细节曝光，亚马逊禁止其站内结账**  
Muse 可逛零售站、展示候选并在用户确认后结账（Stripe Link / Shop Pay）；亚马逊以违条款等为由封锁，Muse 已登顶美区 App Store 免费榜。  
来源：[CNBC](https://www.cnbc.com/2026/10/03/meta-muse-shopping-ai-agent.html)

**值得关注**  
Agent 能力在落地（共享工作区、购物代理），资本在买 Agent 网络护栏，国会则用强制护栏对冲白宫自愿协议——「谁对 Agent 失控负责」会继续升温。
